# Roadmap FletchScore

- [ ] Modèle de données (Compétiteur, Club, Style, Competition, Épreuve,
      Bareme, Inscription, Score, Token)

- [ ] Import/export référentiels (clubs.csv, styles.csv, competiteurs.csv)
- [ ] Couche `scoring/` : calcul de score, classement, départage au X
- [ ] GUI organisateur (customtkinter) : saisie de score par volée
- [ ] Export résultats (Excel, PDF, CSV) + podiums
- [ ] Vue compétiteur web : consultation classement (lecture seule)
- [ ] Vue compétiteur web : proposition de score + file de validation
- [ ] Mécanisme de token (QR code + code court) et rattachement a
      posteriori
