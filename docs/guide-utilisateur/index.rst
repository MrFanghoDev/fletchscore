===========================================
Guide utilisateur
===========================================

.. admonition:: Pour qui ?
   :class: note

   Ce guide s'adresse à l'organisateur qui utilise FletchScore pour
   enregistrer les scores d'une compétition -- pas à un développeur.
   Pour le détail technique (modèle de données, architecture, règles du
   règlement), voir le :doc:`../cahier-des-charges/index`.
